# Calculadora CIDR Avançada

Uma extensão prática para calcular **máscaras de rede (CIDR)** e obter informações detalhadas sobre sub-redes de forma rápida e intuitiva.

## ✨ Funcionalidades

- Inserção de um **IP base** (opcional) para cálculos.  
- Seleção do **prefixo CIDR** desejado.  
- Cálculo automático de:  
  - Máscara de Sub-rede  
  - Máscara Coringa (Wildcard)  
  - Número total de endereços  
  - Endereço de Rede  
  - Endereço de Broadcast  
  - Intervalo de Endereços Usáveis  
- Interface simples e amigável, otimizada para técnicos e estudantes de redes.  

## 🚀 Benefícios

- Facilita o planejamento e configuração de redes IPv4.  
- Evita erros manuais em cálculos de sub-redes.  
- Útil para **sysadmins, técnicos de redes e estudantes**.  

## 📦 Instalação

### 🔹 Google Chrome
1. Clone ou baixe este repositório.  
2. No navegador, acesse:  

chrome://extensions/

3. Ative o **Modo do desenvolvedor** (canto superior direito).  
4. Clique em **"Carregar sem compactação"**.  
5. Selecione a pasta do projeto.  
6. A extensão estará disponível no menu de extensões do Chrome.  

### 🔹 Microsoft Edge
1. Clone ou baixe este repositório.  
2. No navegador, acesse:  

edge://extensions/

3. Ative o **Modo do desenvolvedor** (canto inferior esquerdo).  
4. Clique em **"Carregar sem compactação"**.  
5. Selecione a pasta do projeto.  
6. A extensão aparecerá no menu de extensões do Edge.  

## 🖥️ Como Usar

1. Abra a extensão no navegador.  
2. (Opcional) Informe um **IP base**.  
3. Escolha o **prefixo CIDR** no seletor.  
4. Clique em **Calcular Detalhes**.  
5. Veja instantaneamente todos os resultados sobre a sub-rede: máscara, wildcard, rede, broadcast e IPs usáveis.
